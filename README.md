## Featured Work

### SecureRAG

An evaluation-first RAG platform for financial question answering over SEC filings.

What it includes:

- FastAPI backend with `/query`, `/ingest`, and health endpoints.
- Hybrid retrieval using dense embeddings, BM25 sparse search, and reciprocal rank fusion.
- HyDE expansion, CrossEncoder reranking, and structured LLM generation.
- OWASP LLM security controls for injection blocking, PII anonymization, and output validation.
- Evaluation harness with golden datasets, adversarial tests, and quality thresholds.
- Next.js frontend for querying the system.
